What each node actually does

NodeTypeReal logic
plannerLLMOne structured-output call, classifies the query into 1+ {agent, focus} tasks. Falls back to a single vector_kb_agent task if the LLM returns none or fails to parse.
vector_kb_agentdeterministicCalls search_knowledge_base() — vector retrieval against the KB. No LLM call inside this node itself.
lms_ops_agentdeterministicKeyword-routes to get_leave_balance_tool() / get_leave_history_tool() — live MCP call, no LLM.
sql_db_agentdeterministicHonest stub — no HR operational DB exists yet, returns a fixed "not available" string.
lms_analytics_agentdeterministicHonest stub — no historical analytics dataset exists yet, same pattern.
web_search_agentdeterministicCalls the Tavily client directly. No LLM call inside this node itself.
reviewerLLM (conditional)0 results → fixed fallback string. 1 result → returned as-is, no LLM call spent. 2+ results → one LLM call merges them.

        list[dict], operator.add
    ]
    answer: str

State management today

In-memory, per-request only. No LangGraph checkpointer is configured (graph.compile() takes no checkpointer argument) — state exists only for the duration of one graph.ainvoke() call, then is discarded. Nothing about the graph's own run is persisted anywhere.

Conversation memory (STM) is separate — a plain in-memory Python dict in conversation_memory.py, outside the graph entirely. The route saves only the final answer after the graph finishes; prior turns are never fed back into the Planner's reasoning yet (tracked, on hold).
