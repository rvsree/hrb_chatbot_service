3STM / LTM split
STM — Redis

This conversation's last N turns. Read on every turn, cache-aside: miss falls back to Postgres. TTL'd - an idle conversation ages out of the hot cache, not out of history.

LTM — Postgres

Full durable history of this conversation (system of record, unchanged - conversation_turns). True cross-conversation memory (recalling a different conversation) is NOT part of this - see Decisions.

Write path: every turn writes to Postgres (durable) and Redis (hot cache) together - read path prefers Redis, falls back to Postgres on a miss or Redis outage.
