Key flow
1SEARCH_STRATEGIES[search_strategy] dict lookup - this is the "unknown provider -> clean error" pattern this project applies to every backend choice, not a special case here.
2keyword/hybrid are registered into that same dict dynamically from bm25_search.py (SEARCH_STRATEGIES["keyword"] = search_keyword) rather than hand-added - a real module-import-time side effect, not hidden in the dict literal itself.
3If use_multi_query/use_self_query is set, the chosen base strategy's retriever is wrapped by the LangChain class before the real search runs.
