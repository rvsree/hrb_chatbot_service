Snapshot: 2026-09-22. Model configuration is this project's own (`.env`: OPENAI_CHAT_MODEL=gpt-4.1-mini), a deliberate departure from the IK cohort demo's gpt-4o-mini default - confirmed to keep as-is. No metadata/SQL database is touched on this path - retrieval reads only from the vector store; the metadata DB is an ingestion-side concern. Not shown as its own layer above since it's cross-cutting, not sequential: LangSmith tracing (common/observability/langsmith_tracing.py, built, deliberately off - `.env`'s `LANGSMITH_ENABLED`) and token/cost logging (one log line per LLM call in every client in `common/clients/llm_client/`) apply to every layer above. Validation-gate framing of this same request lives in docs/rag-validation-gates.html; the full 19-stage table lives in docs/rag-pipeline-status.md.
