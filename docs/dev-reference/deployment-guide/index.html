Deployment Guide — hrb_chatbot_v2

Java/Spring Boot → Python/FastAPI/AWS, split by topic. Written 2026-10-05, from a live audit of the deployed service (App Runner, Neon, Pinecone) — not from memory of what was planned. Bookmark this page as the entry point.

Implementation order — not the same as the doc numbering below

Docs 1 and 2 are reference (how to operate what's already deployed, and what already exists in Neon) — nothing to "build" there, read anytime. Doc 6 (NFR/Resilience) is also reference, folded into the other milestones rather than its own build step. The actual build sequence is docs 3 → 4 → 5 → 7, gated by doc 8 at every step:

1. Pinecone (doc 3) → 2. Redis cache (doc 4) → 3. RAG ingestion batch (doc 5) → 4. React UI (doc 7) — LAST

Revised 2026-10-05: Pinecone and Redis both come before the big ingestion build — Pinecone because it's a hard technical prerequisite (Lambda can't use ChromaDB's file-based mode), Redis because it independently fixes an already-broken rate limiter at real App Runner scale. React UI remains the final milestone. See doc 8 for the full gate each step must clear.
