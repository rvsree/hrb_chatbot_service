Deployment Architecture — hrb_chatbot_ui

Static SPA behind CloudFront - no compute, no container, no scaling to think about. Live since 2026-10-23. Icons below use AWS's real per-category colors (Storage green, Networking purple, Security red) - the official AWS Architecture Icon set groups every service this way.

⇄ The honest Java-world comparison

A Spring Boot deploy ends with a JAR running inside something - Tomcat, an EC2 instance, a container on ECS. This component has no such thing: there is no JVM, no application server, no process to keep alive. S3 just holds files; CloudFront just caches and serves them to the nearest edge location. The closest Java-world analogy isn't a running service at all - it's publishing a built frontend bundle to a static artifact host, the way you might push a packaged Angular/React build to Nexus or a CDN from a Jenkins job, except nothing ever executes it server-side.
