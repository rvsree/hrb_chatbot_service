HRB LMS MCP Server Deployment

The 4th real deployable in this system, in a genuinely separate repo (hrb_lms_mcp, not a folder of this one) - included here for completeness, since this guide is otherwise the one place that documents every real deployable's own pipeline. Confirmed live via a direct API call to its own deploy.yml and a real HTTP request to its production URL, not assumed from this repo's own docs.

What this service is. The "specialist"/plan-administrator side of the leave-approval HITL workflow (RAG-ROADMAP.md Phase 162/165/172) - exposes leave-balance/leave-history MCP tools the backend calls, and holds the human specialist review queue. Called by hrb_chatbot_service via real OAuth2 client-credentials auth (Phase 53), never by the frontend directly.

The deploy pipeline

Same proven pattern as this repo's own deploy.yml (doc 1) - same 3 App-Runner-safe build flags, same poll-until-RUNNING pattern, same smoke-test-the-real-URL discipline - run by a dedicated IAM user (hrb-lms-mcp-github-actions-deploy) scoped to only this repo's own ECR repository and App Runner service, never the credentials used elsewhere in this system.
