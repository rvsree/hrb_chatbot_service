RAG Ingestion

Intent, scope, personas, acceptance criteria - the short version.

Overview Spec Architecture Design Decisions Interview FAQ

Intent

Turn an uploaded PDF into chunked, embedded, searchable vectors - reliably, idempotently, without blocking the uploader on how long indexing takes.

Scope

  • Synchronous upload+index (small/batch uploads) and async presigned-upload+Lambda-index (large files, decoupled from the query path) - both real, both in active use, neither replacing the other
  • Content-hash dedup, document supersedes, 6 selectable chunking strategies with auto-selection
  • Out of scope: multi-step tool-calling, agent orchestration - this is a pipeline, not a reasoning loop

Personas

hr_support and admin can upload. Every role queries the index this pipeline builds.

Acceptance criteria

  • Re-uploading identical content resolves to the existing document, never a silent duplicate
  • A document's real current stage is visible at every point - not just "processing" or "done"
  • A failed document records exactly which stage it failed at, with the real error
  • A large upload never competes with live chat queries for API capacity
