2
Key flow
1compute_content_hash() on the raw bytes, then find_by_content_hash() - a match returns status: "duplicate" immediately, nothing else in this flow runs.
2extract_text_from_pdf() - page text joined, tables appended as [TABLE]...[/TABLE] blocks by a separate table extractor.
3chunk_text_with_sections() pulls table blocks back out before chunking, runs the resolved strategy on table-free text, then rejoins the table blocks as whole chunks - a table is never a split target for any of the 7 strategies.
4generate_embeddings() - one batch call for every chunk, computed once, passed into the indexing write rather than re-computed there.
5write_chunks() - a re-index (action: "update") deletes the document's old chunk ids from the vector store first (insert-only API, a reused id would silently no-op); a first index (action: "insert") additionally flips supersedes_document_id's old chunks to is_current: false, once, never repeated on later re-indexes.
6First index only: extract_document_metadata() (category/department/description) runs and is patched onto the already-written chunks - best-effort, a failure here is logged, never fails the index itself.
