Deterministic Execution Harness

Intent classification
Partial
The planner routes a query to domain agents by which tools it needs, not through a dedicated classifier stage. planner_agent (multi_agent_pipeline.py)
Task decomposition
Full
Planner emits a real task list (PlannerOutput.tasks) assigning sub-questions to specific domain agents.
DAG builder
Partial
LangGraph gives a fixed graph topology (add_conditional_edges) — not a DAG assembled fresh per query.
Dynamic tool/agent discovery
Full
MCP registry resolves available tools at runtime (Phase 50), not a hardcoded tool list.
Bounded ReAct loop
Full
Hard iteration cap, configurable: react_loop_max_iterations (default 5). orchestration_agent.py
Dynamic tool router
Partial
Tool args get type-safety from Python/LangChain function signatures — no dedicated validation/routing layer on top.
Isolated sandbox (Docker/E2B/VM)
None
No code-execution sandbox anywhere in the codebase — confirmed via a direct search, not inferred.
Sub-agent spawner (parallel forks)
Full
Real parallel dispatch via LangGraph's Send() fan-out to up to 4 domain agents at once, not asyncio.gather.
Chain-of-thought verification
Full
reviewer_agent independently reviews the planner's routing and the retrieved content before synthesis.
Response synthesis
Full
All 3 pipelines synthesize a final answer from retrieved/tool-returned content; multi-agentic-rag merges multiple domain agents' output.

State Persistence & Context Engine

Tier 1 — active working context
Full
Redis-backed short-term conversation memory, real and live (Phase 247 STM cache).
Tier 2 — durable state store
Partial
Real LangGraph AsyncPostgresSaver checkpointing exists — but only for the Unpaid Leave HITL workflow, not the 3 main RAG pipelines.
Tier 3 — external knowledge & skills
Partial
RAG itself is the project's core (fully built) — but there's no "versioned skills" concept at all.
Durable checkpointing
Partial
Same gap as Tier 2 — real, but scoped to one workflow (unpaid_leave_agent.py), not universal.
Auto-compaction
None
No summarization/compaction of conversation memory found anywhere in the memory layer.
Time-travel (replay/rewind)
None
No state replay or rewind capability found.

Safety, Sandboxing & Governance

Input schema & policy gate
Full
NeMo Guardrails input checks run before every query reaches a pipeline. guardrails_input.py
Permissioned sandbox gate
Partial
OAuth2 scopes exist for MCP tools specifically (mcp:get_leave_balance, etc.) — not a general least-privilege policy for every tool.
Isolation / resource-limited sandbox
None
Same gap as the execution harness's sandbox row — no isolated execution environment exists.
Output validator
Full
Output guardrails run on every answer across all 3 pipelines via the shared guarded-pipeline core. guardrails_output/
Human-in-the-loop gate
Partial
Real interrupt()-based HITL exists — but only for Unpaid Leave requests, not general agent actions.
Circuit breaker
Full
Real failure-threshold/cooldown circuit breakers for both LLM providers and MCP calls (Phase 259/260).
Self-correction engine
Partial
An iteration bound plus circuit-breaker retries exist — no structured parse-error/diff feedback loop on top.

Telemetry & Eval Harness

Agent trace / spans
Full
@traceable wraps every pipeline's top-level call, every tool call, and every eval-judge call (this session's own Phase 269-271 work).
LangSmith integration
Full
Live in production. Currently rate-limited on the monthly trace quota (a usage-cap issue, not a code gap — see today's own investigation).
Production dashboards
Full
Real Admin Dashboard: CI/CD pipeline status, request metrics, eval runs, live queries — all backed by real data, not mocked.
